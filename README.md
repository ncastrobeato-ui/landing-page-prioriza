# Prioriza

Landing page do **Prioriza**, uma solução desenvolvida para auxiliar equipes de software na organização e priorização de demandas.

O projeto apresenta a proposta da plataforma, o problema enfrentado pelas equipes, seu funcionamento, os critérios utilizados para priorização e uma visão do sistema.

## 📌 Sobre o projeto

O Prioriza foi desenvolvido com o objetivo de tornar o processo de priorização de demandas mais organizado, claro e justificável.

A landing page apresenta:

- O problema enfrentado pelas equipes;
- Dados obtidos durante a validação da ideia;
- Como funciona o processo de priorização;
- Os principais critérios utilizados;
- A Matriz de Eisenhower;
- Uma demonstração visual do sistema;
- Os diferenciais da solução.

## 🖥️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## 🎨 Design

A interface foi desenvolvida seguindo uma identidade visual moderna e tecnológica, utilizando principalmente:

- Azul como cor de destaque;
- Azul-escuro para seções de maior destaque;
- Fundos claros para facilitar a leitura;
- Tipografia moderna;
- Cards e elementos com bordas suaves;
- Layout responsivo.
